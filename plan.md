French Phrase Tetris Project Plan
Overview
French Phrase Tetris is a web-based game where players arrange falling French words (each a single block) into grammatically correct sentences on an 8-block-wide grid. Players cycle through 4 LLM-generated words per block using the spacebar, adjust grammar (gender, number, tense, aspect) with the up arrow, and lock in a choice when placed. Words are generated by Gemini, with a 10% chance of blank blocks as wildcards. Rows clear when they’re 8 blocks long and form a valid phrase, with scoring adjusted for grammatical accuracy. The game blends Tetris mechanics with language-building fun for players of all levels.

Problem Statement
Traditional Tetris lacks a linguistic twist, and language-learning tools often feel uninspired. French Phrase Tetris merges Tetris’s addictive gameplay with French sentence-building, making it accessible and enjoyable for beginners to advanced learners by offering word choice and grammar control within a fast-paced puzzle format.
Target Audience
* Casual gamers and French learners of all levels (beginner to expert).
* Players aged 12+ who enjoy puzzles and creative challenges.

Goals
* Build a web game where players form valid French sentences from falling words.
* Ensure smooth gameplay with minimized latency between drops and LLM responses.
* Create an engaging UI with colorful blocks and animations.
* Complete the project in 2 weeks using LLM assistance within the IDE.

Scope
Features (MVP)
1. Game Grid and Mechanics:
    * 20x8 grid with falling blocks (1 block = 1 word).
    * Left/right arrows move blocks; down speeds drop; spacebar cycles 4 words; up arrow adjusts grammar (gender, number, tense, aspect).
    * 10% chance of blank blocks (wildcards).
2. LLM Word Generation:
    * Gemini generates 4 words per block with all grammar variants, following a French part-of-speech frequency formula.
    * Preview shows all 4 words; dropping block displays one at a time.
3. Row Clearing:
    * Rows clear when 8 blocks wide and Gemini validates them as complete phrases.
    * Maximum score (100 points) for perfect grammar; reduced points (100 - 10 per error) for structurally complete but grammatically flawed phrases.
    * 2-second delay before clearing, with errors shown in italics and audio feedback.
4. Scoring:
    * 10 points per block placed.
    * 100 points for perfect row, 90/80/70/etc. for rows with 1/2/3+ grammatical errors.
5. Visuals and Audio:
    * Color-coded blocks (e.g., blue nouns, green verbs, gray blanks).
    * French audio cues: “Bravo” (perfect clear), “Pas mal” (close enough clear), “Putain!” (near stack overflow).
Constraints
* No power-ups or themes in MVP.
* Grammar adjustments limited to gender, number, tense, aspect.
Non-Goals
* Multiplayer mode.
* Advanced learning features (e.g., translations).

Architecture
* Frontend: Phaser.js for grid, mechanics, and animations.
* Backend: Python (FastAPI) to handle Gemini API calls and word queue.
* LLM: Gemini for word generation and validation.
* Storage: LocalStorage for high scores.
* Deployment: Vercel (frontend), Heroku (backend).

Feature Breakdown
1. Game Grid and Mechanics
    * Initialize 20x8 grid in Phaser.js.
    * Implement block dropping: 10-second drop time at Level 1, reducing by 1 second per level.
    * Add controls: left/right/down (movement), spacebar (cycle 4 words), up arrow (grammar: gender/number/tense/aspect).
    * Display 4-word preview for the next block, showing base word in masculine singular form.
2. LLM Word Generation
    * Backend queries Gemini with current rows (e.g., "Je suis").
    * Prompt: "Provide 4 random French words that continue/fill-in/complete a row or start a new one, following this frequency: 30% nouns, 25% verbs, 20% articles, 15% adjectives, 10% others (adverbs, prepositions). Return with grammar variants."
    * Queue: 4 words per block; lock chosen word on placement.
    * Avoid noun/verb duplicates in a 20-word history.
3. Row Clearing
    * Check row fullness (8 blocks).
    * Backend sends row to Gemini: "Is this a structurally complete phrase, despite grammatical errors, or a grammatically correct phrase?"
    * Clear after 2-second delay if valid (showing italics for errors); lock if invalid.
4. Scoring
    * Track points: 10/block placed, 100/90/80/70/etc. per row based on errors.
    * Increase level (drop speed) every 500 points.
5. Visuals and Audio
    * Render blocks with text (color-coded by part of speech).
    * Play “Bravo” for perfect clears, “Pas mal” for flawed clears, “Putain!” near stack overflow.

Part-of-Speech Frequency Formula
Based on French language patterns:
* Nouns: 30% (e.g., "chat," "maison").
* Verbs: 25% (e.g., "mange," "dort").
* Articles: 20% (e.g., "le," "une").
* Adjectives: 15% (e.g., "noir," "grand").
* Others (adverbs, prepositions): 10% (e.g., "bien," "sur").Gemini adjusts words to fit this distribution, providing grammar variants (e.g., "marche," "marché," "marchant").

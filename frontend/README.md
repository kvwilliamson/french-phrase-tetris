# French Phrase Tetris
A Tetris game where you align French words to form valid phrases.

## Setup
1. Clone the repo: `git clone https://github.com/kvwilliamson/french-phrase-tetris`
2. Navigate to the directory: `cd french-phrase-tetris`
3. Start a local server: `npx http-server`
4. Open `http://localhost:8080` in your browser.

## Controls
- Left/Right Arrows: Move block
- Down Arrow: Speed up fall
- Spacebar: Cycle word
- Enter: Start game
- M: Mute/unmute music
